# Codex Tools - Multi-Account Manager & Dashboard

Codex ve ChatGPT hesapları arasında hızlı, güvenli ve sorunsuz geçiş yapmayı sağlayan gelişmiş oturum ve hesap yönetim aracı.

## Özellikler

- **Çoklu Hesap Yönetimi**: Farklı Codex ve ChatGPT hesapları arasında anında geçiş.
- **Güvenli Oturum Depolama**: WebView ve Electron roaming oturum verilerinin kusursuz yedeklenmesi ve geri yüklenmesi.
- **Modern Web Dashboard**: Kullanıcı dostu ve modern arayüz ile kullanım limitlerini ve hesap durumlarını takip etme.
- **Otomatik Başlatma & Hızlı Erişim**: `Baslat.bat` ile arka planda sorunsuz çalışma.

## Başlatma

```bat
Baslat.bat
```
veya
```bash
python dashboard.py
```
Arayüze `http://127.0.0.1:8989` adresinden erişebilirsiniz.
